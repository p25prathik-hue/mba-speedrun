One node per concept, not per course session

Each node is a micro-topic: one concept a student can learn in 45 to 150 minutes. When the same concept is taught in several courses (regression in QM-2, BRM and Marketing-III), it becomes one node tagged with every course. That is how overlaps are removed without losing the curriculum mapping.

id, name, domain, primary_course, all_courses, term, size, base_minutes, value_1to5
QNT26, Simple linear regression, Quant & Analytics, QM-2, QM-2;BRM;FM, 2, L, 150, 5
  • term is the earliest term in which any tagged course teaches the concept. Financial Markets runs in Terms 1 and 2, so its topics carry their own term.
  • size S, M or L maps to 45, 90 or 150 minutes of base self-study time (ti). These are first estimates, to be calibrated by the student survey.
  • value (1–5) is importance for exams and placement prep. It is used only in crunch mode (the orienteering extension).

Three kinds of links

Prerequisites are stored as an edge list, one row per link:

from_id, to_id, type, or_group
FIN25,   FIN26,  AND,
QNT31,   OPS07,  OR,   OPS07-OR0
QNT26,   OPS07,  OR,   OPS07-OR0
QNT02,   FIN08,  SOFT,
  • AND: a hard prerequisite. In the integer program it becomes ui + 1 ≤ uj.
  • OR: rows that share an or_group are alternatives, and any one unlocks the topic. Forecasting can be reached through time series or through regression. These use the ykj constraints in the formulation.
  • SOFT: helpful but not required. Soft links impose no constraint; they lower the transition cost when the two topics are learnt close together.

Cleaning rules applied

  • No cycles. A topological sort must succeed, otherwise no valid roadmap exists.
  • Transitive reduction. If A→B→C exists, a direct A→C link is dropped as redundant.
  • Merge, don't duplicate. A concept repeated across courses is one node with several course tags.
  • Similar is not a duplicate. Closely related but different topics stay separate. Their relatedness goes into the similarity score that drives transition costs.

What is not stored

Transition costs cij are not stored as a 266 × 266 matrix. They are computed when needed from domain membership, similarity and the soft links, using the formula in the proposal. That keeps them easy to vary in sensitivity analysis.

Depth and layout

The Web view places each topic in a column by its depth: the length of the longest prerequisite chain leading to it. Column 0 holds the 19 topics with no prerequisites. Depth is the number of "waves" a strictly layered plan would need, and it gives a quick lower bound on how sequential the curriculum is.
